One original joke about Monday mornings: the one day my bed and my boss finally agree with each other. `main.py` writes that single line (76 characters) to `/output/entry.txt`. Standard library only, no input, no network, same bytes on every run.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
MONDAY_OUTPUT_DIR=./out python3 main.py   # or write ./out/entry.txt
```
